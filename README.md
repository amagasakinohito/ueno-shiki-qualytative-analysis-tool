# 当番活動研究(幼児教育実践学会 発表準備)

幼児教育実践学会でのポスター発表に向けて、当番活動に関する実践研究をまとめるためのリポジトリ。

## 研究の進め方

- 各担任(3歳児・4歳児・5歳児)がエピソードを持ち寄り、対話を通して考察を深める
- 精緻な分析よりも「なんとなくこうではないか」という実感・仮説を大切にし、ポスターにまとめる
- 話し合いは録音・文字起こしし、AIで整理して記録として蓄積する
- 思いついたことは随時ガルーンの実践学会スレッドにメモを投稿し、まとめに反映する
