# 保育公募情報

阪神間・大阪の各市HPから、**保育所／児童発達支援／学童保育（放課後児童クラブ）** の
新規開業（整備事業者公募）および公設民営・民間移管の募集情報を集めるためのフォルダ。

## 対象自治体

兵庫県：西宮市・尼崎市・芦屋市・宝塚市・伊丹市
大阪府：大阪市・豊中市

## 調査時の重要な制約（必読）

今回の調査は Claude Code の実行環境から行ったが、**各市の公式サイトへの直接アクセスが
組織のネットワークポリシーによって遮断されている**（すべて `403 Forbidden`）。

そのため本フォルダの内容は **検索エンジン経由で得られた情報にもとづく二次情報** であり、

- 募集の受付期間・締切
- すでに受付終了しているかどうか
- 募集要項の細目（定員・補助上限・対象地域）

については **必ず各市の該当ページまたは担当課への確認が必要**。
URLと担当課は各ファイルに記載している。

## 更新の考え方

- 「調査結果_YYYY-MM-DD.md」を随時追加し、過去分は残す（いつ何が出たかの記録になる）
- 監視対象URL一覧は、市のサイトリニューアルでURLが変わるため、リンク切れを見つけたら都度直す
